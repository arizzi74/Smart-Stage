GET SMART STAGE

One command. Ready to set up.

Latest release & checksums ↗

The installer detects your architecture, downloads the matching app and opens Admin. You can close the terminal afterward.

M

Mac

macOS 12 or newer · Apple Silicon + Intel

Paste into Terminal:

curl -fsSL https://raw.githubusercontent.com/arizzi74/Smart-Stage/main/install.sh | sh

Installs Smart Stage.app in your Applications folder. The installer removes quarantine only from the downloaded app.

W

Windows

Windows 11 · ARM64 + Intel/AMD64

Paste into a normal PowerShell window:

irm https://raw.githubusercontent.com/arizzi74/Smart-Stage/main/install.ps1 | iex

Installs for your user, adds shortcuts and checks Microsoft WebView2 for the dedicated Admin window.

Prefer a ZIP?

Download your version, extract it and open the app. Check the manual installation notes for Mac permissions and Windows prerequisites.

OPTIONAL LINUX GATEWAY

Bring your remote onto HTTPS.

Public gateway mode is the default and requires a configured public server plus internet access. Deploy the separate gateway on Linux ARM64 or AMD64 with systemd. The installer offers existing nginx HTTPS sites, or Caddy if nginx is absent.

Only control traffic passes through the gateway. Admin and media stay on your computer. Local network mode works without a gateway.

On your public Linux server:

curl -fsSL https://github.com/arizzi74/Smart-Stage/releases/latest/download/install-gateway.sh | sh

A FEW THINGS TO KNOW

Before you press play.

Do I need a server or an internet connection?

The default Public gateway mode needs your own configured gateway server and internet access. It lets phones connect over Wi-Fi or cellular data without opening an inbound remote-control port on the show computer. Choose Local network to use the same trusted LAN without a gateway; allow the app through the firewall when prompted. Local LAN control uses unencrypted HTTP.

Where do my files and playback live?

On your Mac or Windows computer. The native chooser and file drops reference the original paths; they do not upload or copy your media. Keep those files available while using the show. Phones send commands, and Admin stays local on 127.0.0.1.

Why might macOS or Windows show a security prompt?

Mac builds are ad-hoc signed, not Apple Developer ID signed or notarized. Windows builds are not Authenticode signed. A browser-downloaded app may need per-app approval. The Mac installer verifies the release checksum and removes quarantine only from Smart Stage. Read the manual installation notes before opening a downloaded ZIP.

Will an update interrupt my show?

Updates install automatically when Smart Stage launches, before playback begins. An update found during a session waits for the next launch. Saved shows remain in place, and playback does not resume automatically after a restart. Reconnect your remote using the new QR code.

Can the phone or tablet screen stay awake?

The remote has an optional Keep awake control. It works over HTTPS in browsers that support Screen Wake Lock. The control reports its actual status; switching apps, power saving or manually locking the device can release it. Local LAN HTTP addresses require HTTPS for this feature.
