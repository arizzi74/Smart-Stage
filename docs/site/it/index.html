DALLE PROVE AL FINALE

Concentrati sullo spettacolo.

Per presentazioni, prove, eventi dal vivo e piccole produzioni che richiedono comandi di riproduzione chiari e immediati.

01

La playlist, a colpo d’occhio

Trascina i file dal Finder o da Esplora file, scegli nomi e colori e nascondi i pulsanti che non servono a chi controlla lo show.

02

Immagini e suono, insieme

Scegli gli altoparlanti e lo schermo per la proiezione. Usa un’immagine o un video in loop come sfondo e cambia immagine mentre la musica continua.

03

I comandi sempre a portata di mano

Scansiona il QR code di Admin per collegarti. Usa Stage on/off per lo schermo, le dissolvenze audio opzionali e il pulsante STOP. Quando Smart Stage è la finestra attiva, Esc interrompe ogni suono e chiude la proiezione.

SCARICA SMART STAGE

Un comando per iniziare.

Ultima versione e checksum ↗

Il programma di installazione rileva l’architettura, scarica l’app adatta al computer e apre Admin. Al termine puoi chiudere il terminale.

M

Mac

macOS 12 o successivo · Apple Silicon + Intel

Incolla in Terminale:

curl -fsSL https://raw.githubusercontent.com/arizzi74/Smart-Stage/main/install.sh | sh

Installa Smart Stage.app nella cartella Applicazioni del tuo utente. La quarantena viene rimossa soltanto dall’app scaricata.

W

Windows

Windows 11 · ARM64 + Intel/AMD64

Incolla in una normale finestra di PowerShell:

irm https://raw.githubusercontent.com/arizzi74/Smart-Stage/main/install.ps1 | iex

Installa per il tuo utente, aggiunge i collegamenti e verifica Microsoft WebView2, necessario per la finestra Admin dedicata.

Preferisci uno ZIP?

Scarica la versione per il tuo computer, estraila e apri l’app. Consulta le istruzioni per l’installazione manuale per le autorizzazioni su Mac e i prerequisiti su Windows.

IL TUO PRIMO SHOW

Prepara lo show in quattro passi.

  1. 1

    Aggiungi i file

    Trascina audio, video o immagini in Admin, oppure fai clic su Choose Media… per selezionarli. Gli originali restano al loro posto.

  2. 2

    Prepara la scena

    Scegli l’uscita audio e lo schermo. Assegna nomi e colori ai pulsanti, poi imposta uno sfondo se lo desideri.

  3. 3

    Scegli la connessione

    Apri Remote control → Connection settings. Configura un gateway pubblico, oppure scegli Local network per la rete locale e segui le indicazioni sul firewall.

  4. 4

    Scansiona. Tocca. Riproduci.

    Scansiona il QR code con telefono o tablet. Lascia Smart Stage in esecuzione sul computer e tocca un pulsante per avviare il contenuto.

GATEWAY LINUX OPZIONALE

Porta i comandi remoti su HTTPS.

Public gateway è la modalità predefinita e richiede un server pubblico configurato e l’accesso a internet. Installa il gateway separato su Linux ARM64 o AMD64 con systemd. Il programma di installazione propone i siti HTTPS nginx esistenti, oppure Caddy se nginx non è presente.

Il gateway trasmette soltanto i comandi. Admin e i file rimangono sul computer. La modalità Local network funziona senza gateway.

Sul tuo server Linux pubblico:

curl -fsSL https://github.com/arizzi74/Smart-Stage/releases/latest/download/install-gateway.sh | sh

QUALCHE INFORMAZIONE UTILE

Prima di avviare lo show.

Servono un server o una connessione internet?

La modalità predefinita Public gateway richiede un tuo server gateway configurato e l’accesso a internet. Consente ai telefoni di collegarsi tramite Wi-Fi o rete mobile senza aprire una porta in ingresso per il controllo remoto sul computer dello show. Scegli Local network per usare la stessa rete locale fidata senza gateway; autorizza l’app nel firewall quando richiesto. Il controllo sulla rete locale usa HTTP non cifrato.

Dove rimangono i file e dove avviene la riproduzione?

Sul tuo Mac o PC Windows. La selezione nativa e il trascinamento dei file fanno riferimento ai percorsi originali: i contenuti non vengono caricati su un server né copiati. Mantieni i file disponibili mentre usi lo show. I telefoni inviano comandi e Admin rimane accessibile solo sul computer, all’indirizzo 127.0.0.1.

Perché macOS o Windows potrebbero mostrare un avviso di sicurezza?

Le versioni Mac hanno una firma ad hoc, ma non una firma Apple Developer ID né la notarizzazione. Le versioni Windows non hanno una firma Authenticode. Un’app scaricata dal browser potrebbe richiedere un’autorizzazione specifica. Il programma di installazione per Mac verifica il checksum della versione e rimuove la quarantena soltanto da Smart Stage. Leggi le istruzioni per l’installazione manuale prima di aprire uno ZIP scaricato.

Un aggiornamento può interrompere lo show?

Gli aggiornamenti si installano automaticamente all’avvio di Smart Stage, prima della riproduzione. Se un aggiornamento viene trovato durante una sessione, attende l’avvio successivo. Gli show salvati restano disponibili e la riproduzione non riparte automaticamente dopo il riavvio. Ricollega il telefono o tablet usando il nuovo QR code.

Posso tenere acceso lo schermo del telefono o tablet?

Il controllo remoto offre il pulsante opzionale Keep awake per mantenere acceso lo schermo. Funziona tramite HTTPS nei browser che supportano Screen Wake Lock. Il pulsante mostra lo stato effettivo: cambiare app, attivare il risparmio energetico o bloccare manualmente il dispositivo può disattivare questa funzione. Con i collegamenti HTTP della rete locale, questa funzione non è disponibile.
