# Website UI tutorials

These clips show real Smart Stage Admin interactions with **sample data**. They
serve the current embedded HTML, CSS and JavaScript through the production Go
HTTP API and application service on an isolated loopback port.

The fixture replaces native media inspection and device enumeration with known
data. Clicking **Choose Media…** calls the actual authenticated chooser endpoint;
a delayed test callback supplies an original file path to `AppendHostFiles`.
The operating-system chooser is omitted, not imitated. Output selection saves
through the real API. Gateway configuration uses `stage.example.com` and all-zero
placeholder tokens; its connection is simulated and no public server is
contacted. The visible link and QR code are generated by the real Admin UI/API.
These clips do not demonstrate native playback, OS dialogs or hardware routing.

## Reproduce

Requirements: Go, Node.js, Python with Pillow, and the repository's pinned
Playwright browser tools. If the browser tools are not already installed:

```sh
npm ci --prefix scripts/browser --ignore-scripts --no-audit --no-fund
node scripts/browser/node_modules/playwright/cli.js install chromium
```

From the repository root:

```sh
node scripts/demo/capture.cjs
```

The default records English and Italian. For local iteration, pass `en` or `it`;
run without arguments for the final complete provenance report. Capture the two
languages from the same unchanged application source.

The driver compiles `fixture_test.go.txt` with a Go test overlay. The fixture is
never linked into the application or gateway. Each scenario starts a fresh
fixture, captures the actual panel without modifying its DOM/CSS, and terminates
the server afterward. The original screenshot frames and fixture logs remain in
the printed temporary directory for review. Full-page Italian screenshots are
also retained there for copy review.

Pillow resizes the panel screenshots, pads changing panel heights with the app's
plain background, and encodes a shared 128-color palette. Static PNG posters use
the final frame. Durations include pauses around each interaction; GIF frames
with unchanged pixels may be coalesced. The website starts with posters and autoplays each clip while visible, unless
reduced motion is requested. Play/stop controls let viewers make a manual choice;
without JavaScript, the poster links directly to the GIF.

Outputs under `docs/site/assets/demos/`:

- `add-media-en.gif` / `add-media-it.gif`: click Choose Media, append a file,
  change its label and choose a color. Playlist edits save automatically.
- `outputs-en.gif` / `outputs-it.gif`: select speakers/display and save outputs.
- `remote-en.gif` / `remote-it.gif`: configure the example gateway, save, then
  collapse settings to reveal the link and QR code.
- A matching `.png` poster for each GIF.
- `overview-admin-it.png` (1400×1070) and `overview-remote-it.png` (430×860): Italian overview
  screenshots using the same fixture, six sample cues and a loopback remote.
  The simulated stage reports on; this is not evidence of a hardware display.
- `provenance.json`: source revision, browser, embedded-asset/tooling hashes,
  dimensions, durations, output hashes and explicit fixture limitations.

No recording contains real credentials or private user media paths. The example
URL and QR code are intentionally nonfunctional.
